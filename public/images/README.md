# FemStudio Image Asset Library

Images are organized by content type and should use SEO-friendly lowercase filenames.

## Canonical Folders

```
public/images/
├── editorial/
├── headshots/
├── celebrations/
├── founder/
├── webdesign/
├── brand/
└── og/
```

Do not recreate `public/images/portfolio/photography/` or `public/images/portfolio/web/` inside this project. Those were old source paths only.

## Naming Rules

- Use lowercase, hyphenated filenames.
- Include Houston where the asset is location-relevant.
- Include the service type where useful: headshot, photography, web-design, editorial.
- Use descriptive alt text in components.

Examples:

- `professional-headshot-houston-01.jpg`
- `porsche-editorial-brand-photography-houston-model-car-hero.jpg`
- `prom-photography-houston-01.jpg`
- `john-adeniran-femstudio-houston-photographer.jpg`
- `og-photography.jpg`
